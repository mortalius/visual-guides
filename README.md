# Visual guides

Интерактивные визуальные гайды по инфраструктурным темам. Каждый гайд - самодостаточная
статическая страница: без сборки, без фреймворков, без зависимостей кроме Google Fonts.
Общий визуальный язык - тема «Blueprint Journal» (инженерный журнал / чертёж): цвет несёт
смысл роли элемента, а не украшает.

## Гайды

| Гайд | О чём | Стек |
|------|-------|------|
| [`envoy-gateway-visualization/`](envoy-gateway-visualization/) | **Envoy Gateway и Gateway API**: связи между CRD, путь трафика по шагам, точки применения политик, режимы развёртывания и миграция с Ingress. Клик по узлу раскрывает назначение, связи и живой пример манифеста. | HTML + SVG, CSS, vanilla JS |
| [`traces-tempo/`](traces-tempo/) | **Путь трейса**: обработка, фильтры и семплинг в otel-collector и Tempo - head sampling, `tail_sampling`, лимиты ingestion, границы блоков, чтение и производные данные. | HTML, CSS, vanilla JS |

## Запуск локально

**Http-сервер обязателен.** Гайды подгружают части через `fetch`, а он блокируется на
`file://` политикой CORS - при открытии файла напрямую страница останется пустой.

```bash
cd <папка гайда>
python3 -m http.server
# → http://localhost:8000
```

## Структура гайда

Внутри каждой папки - своя документация:

- `README.md` - представление: что из чего состоит, где что менять.
- `DESIGN.md` - визуальный язык: палитра, типографика, паттерны компонентов.
- `index.html` - оболочка; контент вынесен в `data.js`, поведение в `app.js`, стиль в `styles.css`.

Разделение осознанное: большинство правок - это текст в `data.js`, и для них не нужно
трогать ни разметку, ни логику.

## Лицензия

Образовательные материалы. Все примеры манифестов - синтетические, не привязаны к какой-либо
конкретной инсталляции.
