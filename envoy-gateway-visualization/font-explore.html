Typography · сравнение вариантов

Пять типографических систем для Envoy Gateway vis

Одна и та же карточка-макет отрисована пятью разными шрифтовыми трио. Меняются только шрифты (дисплейный / текстовый / моно) - палитра, отступы и компоненты одинаковы, чтобы сравнение было честным. Вариант 1 - текущий стиль, варианты 2-5 - предложения.

Ключевая находка. Интерфейс на русском, но текущие шрифты Fraunces и Hanken Grotesk не содержат кириллицы. Поэтому все русские заголовки сейчас падают на Georgia, а весь русский текст - на системный system-ui. То есть подобранная типографика реально работает лишь на латинских техметках (KIND, YAML), а сам контент отображается запасными шрифтами. Все варианты 2-5 подобраны с полной поддержкой кириллицы.
01 / текущий Blueprint Journal (as-is) кириллица: только mono
Display: Fraunces 600 · нет кириллицы → Georgia Text: Hanken Grotesk · нет кириллицы → system-ui Mono: JetBrains Mono ✓

Как есть сейчас. Редакторский серифный дисплей + чистый гротеск + техно-моно. Задумка отличная, но на кириллице разваливается: заголовок ниже - это Georgia, а не Fraunces; тело - системный шрифт.

Reference · Gateway API

Envoy Gateway интерактивный гайд

Визуальный разбор для инженеров: как связаны CRD, каким путём идёт трафик и где применяются политики. Кликайте узлы - раскрываются назначение, связи и пример манифеста HTTPRoute.

HTTPRoute
Маршрут HTTP-запросов
gateway.networking.k8s.io/v1
Характеристики
parentRefs - привязка к Gateway и слушателю.
rules[].matches - условия совпадения пути и заголовков.
namespacedv1 GASIG-Network
# маршрут «префикс /api → сервис»
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: api-route
spec:
  parentRefs:
    - name: eg-gateway
  rules:
    - matches:
        - path: {value: /api}
      backendRefs:
        - name: api-svc
          port: 8080

02 / предложение Editorial Contrast полная кириллица
Display: Playfair Display 600/700 ✓кир Text: Inter ✓кир Mono: JetBrains Mono ✓кир

Сохраняет исходный замысел. Playfair - высококонтрастный редакторский сериф «в духе Fraunces», но с настоящей кириллицей. Inter - эталон UI-гротеска, нейтральный и очень читаемый. Максимальный контраст «дисплей ↔ тело», журнальная эстетика остаётся. Минимальная миграция - меняются два шрифта, mono тот же.
