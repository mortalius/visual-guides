Ссылки между ресурсами

Стрелка = поле, которым ресурс ссылается на другой
ссылка через поле spec (*Ref) владение: контроллер владеет классом (не ссылка, не трафик) привязка политик (см. слой «Политики»)
Две точки привязки EnvoyProxy. На него ссылаются с GatewayClass (инфраструктура на весь класс) и/или с конкретного Gateway - spec.infrastructure.parametersRef; уровень Gateway перекрывает класс. У ссылки с Gateway нет поля namespace, поэтому EnvoyProxy обязан лежать в namespace этого Gateway. Режим mergeGateways: true живёт только на уровне класса и ссылку с Gateway запрещает. Как складываются уровни - в панели EnvoyProxy, сравнение режимов - на слое «Развёртывание».
