## 1. Хостинг

Артефакт статический (176 КБ, без сборки), но **http-сервер обязателен**: слои подгружаются
через `fetch('layers/*.html')`, на `file://` доска останется пустой. Диплинки живут на
хеше (`app.js:271-287`, вида `#policies/securitypolicy`) и разбираются на клиенте -
серверные rewrite-правила не нужны, ссылка на конкретный узел заработает на любом CDN.

- [ ] Выбрать хостинг. Рекомендация - **Cloudflare Pages**: бесплатно без лимита трафика,
      свой домен с автоматическим TLS, деплой прямым залитием папки.
      Альтернативы: GitHub Pages (код виден рядом, но софт-лимит 100 ГБ/мес),
      GitLab Pages (требует `.gitlab-ci.yml` даже для статики).
- [ ] Решить вопрос с доменом. `*.pages.dev` в ленте читается как пет-проект;
      если визуализаций будет больше одной - взять один домен и вешать их поддиректориями.
      Тогда ссылка из старого поста не умрёт при смене хостинга.
- [ ] Зафиксировать финальный URL - он нужен для шага 2.
